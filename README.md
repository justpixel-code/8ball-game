## 🛠️ Installation

Follow these steps to download and run the game on your computer.

### Step 1: Install Git & Python
Before running the code, make sure you have Git and Python installed:
* **Download Git:** Visit [git-scm.com](https://git-scm.com) and download the installer for your OS (Windows, Mac, or Linux).
* **Download Python:** Visit [python.org](https://python.org) and download **Python 3.6 or higher** (Python 3.11 recommended). **Important for Windows:** Make sure to check the box that says **"Add python.exe to PATH"** during the installation.

### Step 2: Clone the Repository
Open your terminal (Command Prompt, PowerShell, or Git Bash) and run the following command to download the project:
```bash
git clone https://github.com/justpixel-code/8ball-game/
```

### Step 3: Navigate to the Project Folder
Move inside the project folder by running:
```bash
cd 8ball-game
```

---

## 🚀 How to Run

Once you are inside the project folder, you can start the game by running the `main.py` file:

```bash
python main.py
```
